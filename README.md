## About this collection

These are solutions I came up with while working through Codewars kata. Most were solved during **2020–2021**, with **no AI assistance and minimal help from the web**. This repository is a record of my own problem solving and practice across several programming languages.

The challenges range from string manipulation and number sequences to Sudoku validation, Morse code decoding, and poker hand evaluation. Each solution below links directly to its source file.
